- Title: Dockerizing Reservations Application and Setting Up MongoDB 
- Introduction: 
    The process of creating a microservice for authentication begins with Dockerizing the existing reservations application.
    This approach will facilitate running multiple applications simultaneously using Docker Compose. 
- Key Points: 
    1. Preparation: 
    • Ensure Docker is installed on your machine. 
    • A separate video will cover how to install Docker if needed. 
    2. Creating Dockerfile: 
    • Navigate to the reservations folder and create a `Dockerfile`. 
    • The `Dockerfile` serves as a template that outlines how to build the application. 
    3. Setting Up the Dockerfile: 
    • Extend from the Node Alpine image for the base. 
    • Set the working directory to `/usr/src/app`. 
    • Copy `package. json` and `npm-lock. yaml` into the container. 
    • Install dependencies using NPM, including `pmpm` globally. 
    • Copy the entire app and run `npm run build` to compile the application. 
    4. Defining the Production Stage: 
    • Create a production image also based on Node Alpine. 
    • Set an environment variable `NODE_ENV` to production. 
    • Copy `package. json` and install only production dependencies with `npm install --prod`, making the image lighter. 
    • Copy the built files from the development stage. 
    5. Running the Docker Container: 
    • Execute the command to build the Docker image. 
    • After building, run the container. An issue arises with MongoDB URI due to an unspecified environment variable. 
    6. Using Docker Compose: 
    • Create a `docker-compose. yaml` to manage running containers more effectively and include environment variable configurations. 
    • Define services, starting with the reservations container and specify the build context and Dockerfile path. 
    • Use the target to run from the development stage ensuring hot-reloading is activated during development. 
    7. Adding a MongoDB Service: 
    • Introduce a MongoDB service in the `docker-compose. yaml`, using the official MongoDB image from Docker Hub. 
    • Adjust the application’s database URI to connect to the Mongo service using the service name rather than localhost. 
    8. Testing and Finalization: 
    • Bring up the containers using Docker Compose, verify logs from both reservations and MongoDB, ensuring that they start without issues and the application is running smoothly. 
- Conclusion: 
    The reservations application is now fully dockerized and operational alongside a MongoDB container.
